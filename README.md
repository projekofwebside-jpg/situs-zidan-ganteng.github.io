# RootLab Android — GitHub Pages

Website statis edukasi mengenai rooting Android, dengan fokus alur umum perangkat Snapdragon yang bootloader-nya mendukung unlock.

## Struktur

- `index.html` — Home
- `prepare/` — Persiapan
- `unlock-bootloader/` — Unlock Bootloader
- `firmware/` — Firmware & boot/init_boot
- `magisk/` — Patch dengan Magisk
- `verify/` — Verifikasi root
- `troubleshooting/` — Troubleshooting
- `pros-cons/` — Kelebihan, kekurangan, manfaat
- `styles.css` — Desain global
- `script.js` — Interaksi ringan

## Dipasang di GitHub Pages

1. Buat repository dengan nama `username.github.io`.
2. Upload seluruh isi ZIP ini ke branch utama (biasanya `main`).
3. Pastikan `index.html` berada di root repository.
4. Pada Settings → Pages, pilih deployment dari branch utama.
5. Buka `https://username.github.io/`.

## Catatan

Panduan root tidak universal. Perintah flashing, nama partisi, kebutuhan unlock resmi, AVB/vbmeta, serta metode recovery berbeda menurut model, codename, region, dan versi Android.


## Grafik
Visual utama dibuat dengan CSS/SVG inline sehingga tajam di GitHub Pages, responsif, dan tidak membutuhkan library chart eksternal.
