Troubleshooting

Panduan bertahap dengan fokus perangkat Android Snapdragon. Sesuaikan detail perintah dengan model dan firmware perangkat Anda.

Diagnostic flow

Cari titik gagal sebelum mengulang flashing.

STOP → IDENTIFY → RECOVER
01

PC tidak mendeteksi

Cek kabel, driver, mode USB, dan apakah perangkat benar-benar berada di fastboot/ADB.

Masih tidak terdeteksi → ganti kabel/port dan uji ulang.
02

Bootloop

Curigai image salah, patch tidak cocok, module bermasalah, atau perubahan boot yang tidak sesuai.

Kembali ke image stock yang sesuai → pulihkan boot.
03

Root hilang setelah update

OTA dapat mengganti boot/init_boot. Root mungkin perlu dipatch ulang memakai firmware baru.

Jangan patch file lama untuk build baru.

Fastboot tidak mendeteksi

Coba kabel USB lain, port lain, restart Platform-Tools, dan cek driver. Jalankan fastboot devices.

Bootloop setelah patch

Masalah paling umum adalah image salah build, patch tidak cocok, atau flashing ke partisi yang keliru. Kembalikan image stock yang sesuai.

Root hilang setelah update

OTA dapat mengganti boot/init_boot. Biasanya image baru perlu dipatch ulang mengikuti metode perangkat.

Aplikasi perbankan menolak

Akses root dapat memicu pemeriksaan integritas perangkat. Jangan mencoba “menyembunyikan” root sebelum memahami risiko dan kebijakan aplikasi.

OEM unlock abu-abu

Pada sejumlah perangkat, status unlock bisa bergantung pada koneksi akun, region, waktu tunggu, operator, atau kebijakan OEM.

Perangkat tidak mau boot

Masuk ke fastboot/recovery, pertahankan firmware stock yang cocok, lalu ikuti restore resmi untuk model tersebut.
